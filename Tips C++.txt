Самое важное:
F2 - сохранить файл
Shift+F4 - создать файл
F7 - создать папку
 
F1 - справка
F3 - просмотр файла
F4 - открыть файл для редактирования
F5 - копировать файл/папку
F6 - переместить/переименовать файл/папку
F7 - создать папку
F8 - удалить файл/папку
F9 - меню
Ctrl+O - закрыть обе панели
Ctrl+P - закрыть неактивную панель
Ctrl+F1 - открыть/закрыть первую панель
Ctrl+F2 - открыть/закрыть вторую панель
Shift+F4 - создать файл
Shift+F9 - сохранить настройки
TAB - переключение между панелями
ESC - выход из редактора
 
Внутри редактора:
F2 - сохранить файл
F7 - поиск
Ctrl+Y - удалить всю строку
Ctrl+F7 - поиск с заменой

    Alt+F8 - перейти на строку
